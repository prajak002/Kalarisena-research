# KalariSena

Physics-grounded, recoverable Kalaripayattu skill transfer for humanoid robots.

- `paper.pdf` — the paper (2026 ACL submission draft).
- `code/` — curated research code from the working repository: MuJoCo/Pinocchio
  physics stack, retargeting pipeline, RL environment/reward scaffolding,
  results and figures.
- `site/` — an interactive research walkthrough (Next.js) explaining the
  paper's method, honestly cross-checked against what is actually implemented
  in `code/`.

Run the site locally:

```
cd site
npm install
npm run dev
```
